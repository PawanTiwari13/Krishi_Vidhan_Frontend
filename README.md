# Krishi Vidhan — Frontend Application

Modern agricultural marketplace frontend built with **Next.js 15 (App Router)**, **React 19**, **TypeScript**, and **Tailwind CSS**.

## Getting Started

1. Copy `.env.example` to `.env.local`.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run development server:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.
